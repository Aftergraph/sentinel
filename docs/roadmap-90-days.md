# 90-day roadmap — Sentinel by Aftergraph

**Wedge guardrail:** Sentinel turns pull requests into merge-ready verdicts. First wedge: CLI review on exact HEAD → SHIP / DO NOT SHIP verdict with cited evidence → GitHub App.

## Days 1-30: Prototype + validation

- Verdict-card + CLI output mocks (static, 1 real PR).
- 5-PR validation runs, scored publicly.
- 20-rule gap list; vendor-doc [VERIFY] confirmation.
- Landing/waitlist draft live (passive).
- **Exit:** prototype scores ≥4/5 and waitlist shows pull, or wedge re-pitched.

## Days 31-60: CLI v0 (B)

- `sentinel review` on exact HEAD: 10-rule pack, SHIP/DO NOT SHIP, resolution memory, STALE on base move.
- Dogfood: every Aftergraph studio PR gets a verdict.
- Free distribution: docs + 5-minute install, OSS repos first.
- **Exit:** 10 repos running CLI in CI weekly.

## Days 61-90: GitHub App wrapper (A)

- One-click install, verdict card update-in-place, rebase webhook → auto-stale.
- Free for public repos; team-tier pricing page (no charge yet).
- Design-partner outreach opens (first active motion).
- **Exit:** App live in marketplace (unlisted ok), 3 design partners.

## Explicitly out of 90 days

Interviews-as-motion (optional later), dashboard, SSO, enterprise, GitLab, auto-fix. No code in this docs phase — prototype sprint first.
