# Brand identity — Sentinel by Aftergraph

> **Naming status: working title, not cleared.** The Sentinel name and final
> product identity are under trademark/collision review
> (`Aftergraph/brand#19`, `Aftergraph/sentinel#7`). This document is
> pre-decision strategy work, not a final identity decision.

**Wedge guardrail:** Sentinel turns pull requests into merge-ready verdicts. First wedge: CLI review on exact HEAD → SHIP / DO NOT SHIP verdict with cited evidence → GitHub App.

## Name: Sentinel by Aftergraph

- **Sentinel** = the guard that never sleeps. It watches every merge, verifies the exact commit, and only then speaks. Authority through vigilance, not volume.
- **by Aftergraph** = sub-brand pattern: the product inherits Aftergraph's verification reputation while staying separable if it ever spins out.
- The name was already in use internally for the independent-verifier role — the product grows out of a real function, not a naming session.

## Rejected alternatives

- **Verdict by Aftergraph** — sharp but narrow: names only the judgment, not the watching. Kept as the verdict-card feature name instead.
- **Overlook by Aftergraph** — dropped: "overlook" means both supervise and miss. Fatal ambiguity for a verification product.
- **Skjold by Aftergraph** — strong Danish shield metaphor, weak internationally. Reserved for a future DK-market edition if needed.

## Voice

Short verdicts, cited evidence, no adjectives. "DO NOT SHIP — 2 findings on exact HEAD `a3f9c1d`: (1) unauthenticated delete route, `routes/admin.mjs:41`; (2) migration without rollback, `db/migrate_014.sql`." Never "looks good overall!" Never praise without a cited check.

## Visual direction (placeholder until design sprint)

Monospace SHAs, green/red verdict pills, evidence links as first-class elements (file:line, not prose). Dark-on-light, high contrast — the artifact must read as a certificate, not a chat message.
